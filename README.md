# 🎖️ MR JOO — بوت واتساب للحماية والإدارة والموسيقى

## طريقة استخدام القائمة
- `.قائمة` ← تعرض الأقسام (9 أقسام مرقّمة)
- `.قائمة 7` ← تعرض أوامر قسم معيّن برقمه (أو باسمه: `.قائمة الحماية`)
- `.قائمة الكل` ← تعرض كل الأوامر مرة واحدة

## 🎵 لو أمر التشغيل/الموسيقى باظ أو بيقول "حدث خطأ أثناء التشغيل"

الميزة دي بتعتمد على واجهة يوتيوب غير رسمية، فممكن تتوقف أو تحتاج كوكيز في أي وقت (مش عيب في الكود، يوتيوب بيغيّر سلوكه من وقت للتاني). الخطوات:

1. شغّل `.تشغيل اسم اغنية` وشوف الخطأ بالظبط، وشوف تيرمينال البوت (فيه سطر يبدأ بـ `⚠️ [موسيقى]`) بيوضّح السبب الحقيقي.
2. لو السبب حاجة زي "Sign in to confirm you're not a bot" أو "LOGIN_REQUIRED" أو تعذر الاتصال، يبقى يوتيوب بيطلب تسجيل دخول من السيرفر بتاعك. الحل: ملف كوكيز.

### إضافة كوكيز (لو محتاج)
1. سجّل دخول على music.youtube.com في متصفحك، وصدّر الكوكيز (إضافة متصفح زي "Get cookies.txt LOCALLY").
2. احفظ الملف باسم `ytmusic.txt` في نفس فولدر `index.js` (جوه فولدر الجلسة لو بتشغّل عن طريق تليجرام).
3. أعد تشغيل البوت.

الملف ده محطوط في `.gitignore` فمش بيترفع لو رفعت المشروع على GitHub.

## 🤖 تشغيل عن طريق تليجرام (أي مستخدم يفتح جلسته)

بوت تليجرام تكون إنت المسؤول عنه، وأي مستخدم يدخل عليه يقدر يربط رقمه ويشغّل جلسة MR JOO خاصة بيه. المستخدم العادي ما يقدرش يتحكم في البوت أو في جلسات غيره.

### الإعداد (مرة واحدة)
1. من @BotFather في تليجرام اعمل بوت جديد (`/newbot`) وانسخ **التوكن**.
2. اعرف **معرفك الرقمي**: ابعت أي رسالة لـ @userinfobot (أو ابعت `/id` لبوتك بعد تشغيله).
3. افتح ملف `config.json` وعدّل:
```
{
  "telegramToken": "123456:ABC...",
  "adminIds": ["123456789"],
  "maxSessionsPerUser": 1,
  "maxTotalSessions": 15,
  "defaultCountryCode": "20",
  "developerWhatsApp": ""
}
```
`adminIds` تقدر تحط فيها أكتر من مسؤول. `adminContact` = يوزر تليجرام بتاعك (بدون @) علشان يظهر زر «تواصل مع الأدمن» للمستخدمين في شاشة الاشتراك (لو سيبته فاضي بيستخدم معرف أول مسؤول). `developerWhatsApp` اختياري (رقمك في واتساب ليظهر في قائمة الأوامر).

### التشغيل
```
npm install
node telegram.js
```
وعلى ويندوز: دوس مرتين على `start-telegram.bat`.

### الاستخدام
- **المستخدم:** `/start` ← «ربط رقم جديد» ← يبعت رقمه ← يستلم كود يكتبه في واتساب (الأجهزة المرتبطة) ← الجلسة تشتغل. من «جلساتي» يوقف/يشغّل/يحذف.
- **المسؤول:** `/admin` للوحة التحكم، و`/users`، و`/ban ID` و`/unban ID`، و`/stop SID` و`/remove SID`، و`/broadcast نص`.
- الجلسات المربوطة بترجع تشتغل تلقائيًا لما تعيد تشغيل المدير.
- لتشغيله في الاستضافة استخدم متغيرات البيئة `TELEGRAM_TOKEN` و`ADMIN_IDS` بدل الملف، وعلى Railway اجعل مسار الـ Volume هو `/data`.

### 💎 نظام الاشتراكات
- من **🛠 لوحة الأدمن** (بتظهر للمسؤول بس) ← **نظام البوت** ← اختار **🆓 مجاني** أو **💎 باشتراك**.
- في وضع «باشتراك»: المستخدم من غير اشتراك يشوف «البوت بنظام الاشتراك» + زر **تواصل مع الأدمن** + زر **إدخال كود الاشتراك**. جلساته بتتوقف مؤقتًا (مش بتتحذف) وبترجع تشتغل لوحدها أول ما يشترك.
- **إنشاء الأكواد:** لوحة الأدمن ← 🎟 إنشاء كود ← اختار المدة (ساعة / يوم / 7 / 30 / 90 / سنة / ♾ دائم / ✏️ مخصصة) ← العدد. أو بالأمر: `/gen 30d 5` أو `/gen 12h` أو `/gen دائم 2`.
- **المستخدم** بيدخل الكود (زر أو `/code` أو يلصقه مباشرة) ← يظهر له **عد تنازلي حي** للمدة المتبقية من `💎 اشتراكي`.
- الاشتراك الفعّال بيتعرف عليه البوت **تلقائيًا** (مفيش إدخال كود كل مرة). لما المدة تخلص (أو الأدمن يلغيه) بيتلغي الاشتراك لوحده، **وبتتحذف جلسة المستخدم ويتفصل جهازه من واتساب**، ويتبعت له إشعار، وتنبيه قبلها بيوم للاشتراكات الطويلة.
- كود جديد لمشترك حالي بيتضاف على المتبقي. كل كود يُستخدم مرة واحدة. 5 محاولات غلط ← قفل 10 دقايق.
- أوامر إضافية للمسؤول: `/grant ID 30d` منح اشتراك مباشر، `/revoke ID` إلغاء، `/mode free|paid`.
- كل بيانات الاشتراكات والأكواد في `data/store.json` — على الاستضافة اربط `DATA_DIR` بـ Volume علشان ما تضيعش.

### حماية مدمجة
- كل جلسة بتشتغل في عملية منفصلة بمجلد بيانات خاص بيها، ومش بتشوف توكن تليجرام.
- المالك داخل كل جلسة هو صاحب الرقم المربوط بس.
- حد أقصى للجلسات لكل مستخدم وللسيرفر كله، وفترة انتظار بين محاولات الربط (علشان محدش يبعت أكواد لأرقام غيره).
- كل جلسة بتاخد حوالي 100 إلى 150 ميجابايت رام، فاضبط `maxTotalSessions` حسب سيرفرك.

## التشغيل محليًا بدون تليجرام (Termux / كمبيوتر)
```
npm install
node index.js
```
سيظهر **كود ربط** في الشاشة (بدون QR) ← واتساب ← الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف ← اكتب الكود.

## إعدادات (متغيرات بيئة اختيارية)
| المتغير | المعنى |
|---|---|
| PAIRING_NUMBER | رقم البوت بكود الدولة (الافتراضي في الكود) |
| SESSION_DIR | مجلد الجلسة (على الاستضافة: /data/session) |
| DB_FILE | ملف البيانات (على الاستضافة: /data/db.json) |
| STORE_DIR | مجلد الوسائط المحفوظة بـ .حفظ (على الاستضافة: /data/store) |

## الاستضافة 24 ساعة

### الخيار 1: Railway (الأسهل)
1. ارفع المجلد على GitHub (مستودع خاص).
2. railway.app ← New Project ← Deploy from GitHub.
3. من Settings أضف **Volume** واجعل مسار التركيب `/data`.
4. من Variables أضف: `SESSION_DIR=/data/session` و`DB_FILE=/data/db.json` و`STORE_DIR=/data/store` و`PAIRING_NUMBER=201029247107`.
5. افتح Logs وستجد كود الربط، اكتبه في واتساب.
بدون Volume سيُطلب منك كود ربط جديد عند كل إعادة نشر.

## ⚡ تحسينات السرعة
- حفظ قاعدة البيانات بقى مؤجّل ومجمّع (كان بيكتب الملف كله مع كل رسالة في المجموعات ويعطّل البوت).
- فاصل الإرسال بين الرسائل المتتالية 120–320ms بدل 700–1500ms (ممكن تغيّره بـ `SEND_MIN_GAP` و`SEND_MAX_GAP`). الرد الأول بيمشي فورًا. لو لاحظت تقييد على الرقم ارفعهم تاني.
- بيانات المجموعة بتتخزن 10 دقايق (بتتحدث فورًا عند أي تغيير)، وتحميل ميديا مكافحة الحذف ما بيعطّلش الأوامر.
- صور الردود اتصغّرت (960px) فرفعها أسرع، والرد على أزرار تليجرام بيمشي بالتوازي.
